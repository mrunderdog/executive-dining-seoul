# Localdata 지역별 음식점 인허가 직접 검증 및 점수 의미 전환

- 정부 지방행정 인허가 CSV: https://file.localdata.go.kr/file/general_restaurants/info
- 대상: 경찰청 연결 식당 18곳이 있는 서대문구(3120000), 중구(3010000), 종로구(3000000), 서초구(3210000).
- 실행: `python pipeline/audit_restaurant_licenses.py --fetch-official --output reports/restaurant-license-audit.json`
- 원본 지역별 다운로드 URL, SHA-256, 바이트 수와 확인 시각을 기록합니다. 어느 하나라도 다운로드 실패하면 성공 보고서를 생성하지 않습니다. CLI 결과에 대해 CI 아티팩트를 보존합니다.
- 주의: 인허가 기록은 업소의 실체·허가 상태를 검증할 뿐 해당 기관의 카드가 그 가맹점에서 결제됐다는 증명이나 특정 공직자의 참석 증빙이 아닙니다.
- 교차기관 점수: 기존 `visits` 계산값은 업무추진비 등의 **공식 공개 사용처 건수**로 명명합니다. 집계 산식(로그 정규화/기관 수/출처 수)은 유지하지만 참여자의 현장 방문으로 표현하지 않습니다. 경찰청 카드 지점 미검증 기록은 교차기관 점수에서 계속 제외하며, 모든 개인의 확인된 방문 값은 새 데이터 없이 0건입니다.
- 과거 리포트의 `visits` 키는 호환성 목적으로 남아 있습니다. 새로운 검증자료가 생기기 전까지 `confirmed_person_attendances`를 사용해 참석 확정 주장할 수 없습니다.
