BEHIND THE MAP · DATA LINEAGE

이 지도는 어떤 데이터로 만들어졌나

기관이 공개한 지출·사용처 기록을 수집하고, 식당 이름과 위치를 검토한 뒤 지도에 반영합니다. 아래 수치는 실제로 공개된 식당 데이터를 기준으로 자동 계산합니다.

↗ DATA

01. 공개 출처별 식당

기관군 · 중복 포함

출처 집계가 준비되지 않았습니다.

식당 수는 출처군별 중복을 포함하므로 위 카드의 합계가 전체 식당 수와 일치하지 않을 수 있습니다. 수집된 원자료 총 행 수 또는 기관 수를 뜻하지 않습니다.

02. 기록에서 지도로

공개 결과의 단계별 집계

처리 단계가 준비되지 않았습니다.

기관 교차 식당은 위치 확인 식당의 하위집합이 아닐 수 있습니다. 숫자는 각 단계의 개별 집계이며, 같은 원자료의 순차적 감소량을 나타내는 퍼널은 아닙니다.

03. 어떤 사실이 검증되었나

근거의 경계를 분리해서 표시
원자료 공개기관이 게시한 거래·사용처 기록
위치 확인표시 가능한 식당 주소 또는 좌표
기관 교차여러 기관의 공개 선택 기록이 겹치는 식당
별도 미확인카드 가맹점 동일성·개인 참석은 자동 입증되지 않음

04. 업데이트 · 품질 상태

마지막 사이트 생성 기준
LAST BUILD확인 중사이트 파일 생성 시각 (KST)
SOURCE GROUPS—지도에 노출된 출처군
QUALITY GATE미확인검증 상태 집계 중
REVIEW QUEUE미확인의회 출처 진단 범위 한정
FETCH FAILURES미집계실제 최신 수집 실패 로그 미통합

최근 공개 거래일: 확인 중. 사이트 생성 시각은 원자료 갱신 또는 GitHub Pages 배포 완료 시각이 아닙니다.

이 지도에 나타난 공개 지출기록만으로 특정 공직자의 직접 참석이나 식당의 품질을 추론할 수 없습니다. 일부 출처는 원천사이트 장애 시 이전 검증 데이터를 유지할 수 있습니다.
