# 공식 결제 지점 검증 — 기관 보유자료 확인 범위 및 대조 대상

> 내부 검증용. 공개 사이트에 게시하는 별도 거래 장부가 아니다. 업무추진비 집행 명의는 특정인의 식당 방문을 증명하지 않는다.

## 현 단계의 결론

- 대상: 이천·안산·화성시의회 공개 원자료 **1,123건**, 후보 업소 **222개**.
- 거래 행에 지점 주소가 있는 건 **0건**, 가맹점 식별자가 있는 건 **0건**.
- 우선확인 대상 **9개 상호·57건**을 `reports/council-payment-location-audit.json`에 날짜/금액/row_id/공식 링크별로 기록했다.
- 동일 업소명, 검색엔진 결과, 업체 홈페이지의 주소, 지도 좌표 또는 체인점 로고는 **특정 카드 결제의 지점 증거가 아니다**.
- 추가 자료를 추정하거나 사업자등록번호·카드번호를 공개용 데이터에 임의 기록하지 않는다.

## 기관별 기보유자료의 확인 범위

공식 홈페이지에서 공개된 월별·분기별 업무추진비 사용내역과, 해당 기관이 *실제로 보유하는 경우*의 카드 사용명세 또는 지출증빙을 대조한다. 별도 자료 존재 여부는 **미확인**이며, 공개 의무나 공개 결정은 자료별로 달라질 수 있다.

이미 보유한 자료로 제공 가능한 범위에 한하여 아래 내용 확인을 요청하는 구성이 적절하다.

1. 아래 표의 거래 일자·금액·가맹점 상호와 연결되는 **지출 장소의 도로명주소 또는 영업점명**.
2. 카드 사용명세 또는 카드매출전표에 표시된 **결제 당시 가맹점명·지점명·주소**(존재하는 경우).
3. 동명이점 구분을 위해 **거래별 동일 가맹점임을 구분할 수 있는 비식별 식별자**(이미 보유하고 있고 공개 가능한 경우).
4. 동일 상호가 서로 다른 지점인지 확인할 수 없다면 이를 명확히 표시. 개인 이름·카드번호·승인번호 등 불필요한 민감정보는 제외 또는 마스킹.

**중요:** 이미 보유하지 않은 자료의 신규 작성은 요청하지 않으며, 개인정보·영업비밀 등에 관한 비공개 또는 부분공개 판단을 존중한다. 카드 명의나 직책만으로 실제 참석자를 추론하지 않는다.

## 증거 수준과 재검증 규칙

**Level 0 — 공식 사용처 상호:** 거래 날짜·금액·상호·첨부 원문만 존재. 지점 미확정.

**Level 1 — 업체 존재:** 외부 업체 주소·사업장 정보가 존재. 거래 지점 미확정.

**Level 2 — 가맹점 연계 후보:** 기관이 보유한 장소·지점 정보가 결제 기록과 연결되지만 유일한 지점 특정 여부 불명확. 게시 지점 미확정.

**Level 3 — 공식 거래별 확정:** 날짜·금액·가맹점 상호·공식 자료의 지점 주소/식별정보가 **해당 원자료의 같은 거래행**과 일치하고 충돌 증거가 없음. 수동 검토 및 재현 테스트 통과 후에만 확정.

Level 3 이전에는 지점 주소로 확정 마커를 추가하거나 서로 다른 상호/지점을 묶어 거래 횟수를 합산하지 않는다.

## 검증 보류 내역

- 이천: `야반`(관고동/아울렛), `서경한우프라자`(마장본점/이천점), `성루`(갈산동/과거 어재연로 기재).
- 안산: `다인`, `다빈`, `양평해장국` — 상호만으로 지점 확정 불가.
- 화성: `훈장골`, `훈장골갈비집` — 유사 상호를 동일 결제 가맹점으로 합산 금지. `뜰안에` — 상호 모호.

## 운영 규칙

- 원본 1,123건 및 원문 링크는 보존한다.
- 추가 자료가 확보되면 `pipeline/audit_council_payment_locations.py`를 재실행한다. **현행 원자료에 새 필드가 추가됐는지**부터 확인하고, 문서 증거는 별도로 검증한다.
- 공개 사이트에 새 장부 페이지를 만들지 않는다.
- 외부 업체 조회로 얻은 주소는 업소 존재 참고자료이지, 과거 카드 결제 지점 증빙으로 자동 승격시키지 않는다.
